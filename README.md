# minno-eat

Sitio web de **MINNO gelato soft** (Hermosillo, Sonora), hecho con [Astro](https://astro.build).

## Para editar el contenido
Todo el texto del negocio (contacto, horario, toppings) está en **`src/data/minno.ts`**.

## Para correrlo en tu computadora
```sh
npm install
npm run dev      # abre http://localhost:4321
npm run build    # genera la carpeta dist/ lista para publicar
```
